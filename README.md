\# Apple Music Assistant



\## LDCW6123 Fundamentals of Digital Competence for Programmer



Apple Music Assistant is an interactive web-based system developed for the LDCW6123 Group Project.



\### Project Description



The system recommends songs based on the user's:



\- Genre

\- Mood

\- Language



The project is developed using:



\- PHP

\- HTML

\- CSS

\- JavaScript

\- Bootstrap 5



\### Main Features



\- Select a preferred music genre

\- Select a mood

\- Select a language

\- Generate a song recommendation

\- Display the recommended song information



\### Project Files



\- `index.php` — Main application and recommendation logic

\- `style.css` — Website styling

\- `script.js` — JavaScript functionality



\### Project Purpose



The purpose of this project is to demonstrate programming concepts and create an interactive system related to Apple Music.
